#### About

I'm a frontend developer, mostly working in React and TypeScript. In my spare time I build Discord bots, and every so often something in Java.

My main project is [Testify](https://github.com/Kkkermit/Testify), an all-in-one Discord bot I've been working on since 2024. Version 2 was a full rewrite in TypeScript. Every command now works as both a slash and a prefix command, and there are close to 6,000 tests behind it.

I sell some of my bots on [Buy Me a Coffee](https://buymeacoffee.com/kkermit/extras). If you have questions about one, message me on [Discord](https://discord.com/users/526853643962679323).

#### Projects

**[Testify](https://github.com/Kkkermit/Testify)** &nbsp;<sub>TypeScript</sub><br/>
All-in-one Discord bot with moderation, economy, music, tickets, games and a web dashboard. Runs at [testify.lol](https://testify.lol).

**[DiscordBotV14-template](https://github.com/Kkkermit/DiscordBotV14-template)** &nbsp;<sub>JavaScript</sub><br/>
Discord.js v14 starter with slash and prefix command handlers and MongoDB set up.

**[Statify](https://github.com/Kkkermit/Statify)** &nbsp;<sub>Java</sub><br/>
Discord bot in Java (JDA) that shows your Spotify listening stats.

**[jest-ts-example](https://github.com/Kkkermit/jest-ts-example)** &nbsp;<sub>TypeScript</sub><br/>
React and TypeScript starter on Vite, set up for Jest, Vitest and Tailwind.
