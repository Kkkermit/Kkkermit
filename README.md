## <img src="https://media.giphy.com/media/hvRJCLFzcasrR4ia7z/giphy.gif" width="28"> &nbsp;whoami

I'm a frontend developer working mostly in **React, Redux and TypeScript**, with a growing amount of **Java and Spring** on the backend. Day job is component architecture and testing strategy; evenings are Discord bots.

The thing I actually care about: code that's **provable**. If a component can't be tested cleanly, it's usually a design problem, not a testing problem. Most of what I ship starts as a failing test.
