# README design previews, round two

All four are built to stay smooth on phones: nothing big moves continuously, the ASCII art is drawn as shapes, and anything you need to read is real text or big enough to read at phone width.

| Option | Feel |
| :-- | :-- |
| [1 · CRT, rebuilt](1-crt) | Your current design, fixed for phones |
| [2 · Studio](2-studio) | Big wordmark, soft glow, plain text below. No animation |
| [3 · Terminal](3-terminal) | Clean terminal window; the banner types out once |
| [4 · Monogram](4-monogram) | Logo mark, full-width project cards, no animation |

This folder gets deleted once a design is picked.
