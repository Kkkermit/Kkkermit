# README design previews

Three options for the profile README. Open a folder to see it rendered by GitHub, animations included.

| Option | Header | Feel |
| :-- | :-- | :-- |
| [1 · Terminal](1-terminal) | `cat kkermit.txt` types out an ANSI Shadow banner with a neofetch-style info panel | Closest to the current layout, recoloured |
| [2 · CRT](2-crt) | Glitching "Bloody" ASCII logo on a scanlined CRT, with a scrolling ticker | Loudest and most stylised |
| [3 · Minimal](3-minimal) | Big name on the left, spinning ASCII donut on the right | Cleanest, most "professional" |

The numbers in the stats cards are from the last daily run; the chosen design will pull them live like before.
This folder gets deleted once a design is picked.
