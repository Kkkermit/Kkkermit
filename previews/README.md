# README design previews, round six

Six different design styles. Flat colours only: no gradients, glows or animation.

| Option | Style |
| :-- | :-- |
| [M · Neo-brutalism](M-neo-brutalism) | Bright blocks, thick outlines, hard offset shadows |
| [N · HUD](N-hud) | Sleek sci-fi interface: thin lines, brackets, a reticle |
| [O · Isometric](O-isometric) | Flat 3D illustration of your stack as layers |
| [P · Risograph](P-risograph) | Two-ink print look: off-register type, halftone dots |
| [Q · Dashboard](Q-dashboard) | Product analytics UI: KPI cards and charts |
| [R · Retro stripes](R-retro-stripes) | 70s-style curved bands in red and purple |

Earlier rounds are in the branch history. This folder gets deleted once a design is picked.
